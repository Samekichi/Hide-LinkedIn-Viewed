# 隐藏 LinkedIn 已查看职位

[English](README.md)

一个简单的 Edge / Chrome 扩展，用于隐藏 LinkedIn 职位列表中标记为 `Viewed` 的职位。

## 功能

- 自动隐藏已查看职位
- 在本地保存开关设置
- 临时恢复当前标签页中的已查看职位
- 不收集或传输用户数据

## 安装

1. 打开 `edge://extensions` 或 `chrome://extensions`
2. 开启`开发人员模式`
3. 点击`加载解压缩的扩展`
4. 选择本项目文件夹
5. 打开/刷新 `https://www.linkedin.com/jobs/`

## 限制

依赖 LinkedIn 的页面结构和可见的 `Viewed` 标签，网站改版后可能需要更新。
